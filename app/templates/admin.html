Backup and restore

Export a signed JSON backup regularly so you can restore records after a free-service restart.

The backup contains sensitive customer, activation, and device data. Store it securely and do not edit it; modified files are rejected. Restore adds missing records, keeps existing records, and never moves a trial start later. It cannot recover changes made after the backup was downloaded.
